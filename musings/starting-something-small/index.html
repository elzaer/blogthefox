Starting something small

17 September 2026

I used to write constantly, and then at some point I stopped, mostly because I couldn’t find a place for it that didn’t feel like a performance. Every platform wants a headline, a hook, a reason for a stranger to stop scrolling. That’s fine for some things. It’s a bad fit for a stray thought you just want to get down before it dissolves.

So this is that place instead. No comments, no algorithm, no drafts pile that guilt-trips me from a dashboard. Just short essays and half-formed ideas, posted when they’re ready and left alone otherwise. If something here is worth passing on, the page itself is built to travel — it’ll carry its own title and description wherever it lands.

I’m not committing to a schedule. That’s the whole point of building it this plainly: there’s nothing here that depends on momentum. A post is just a text file until I decide otherwise.

More soon, or eventually. Both are fine.
